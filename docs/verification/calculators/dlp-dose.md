## Current state and root cause

Live synthetic case: DLP 500 mGy·cm, adult, chest produces 7.00 mSv using k=0.014, but also reports additional lifetime cancer risk 3.500%. Retained browser receipt: `catalog-positive-triage-supplemental.json` under release-simplification `.superpowers/sdd/2026-09-07-verified-baseline/`. This is an observed live output, not an accepted clinical answer.

`DLPDose.jsx` calculates `(effectiveDose / 1000) * 5 * 100`, despite its comment specifying 5% per Sv. The coefficient 5 is already percent per Sv; the final factor 100 introduces a 100-fold error. Dimensional diagnostic: 7 mSv = 0.007 Sv; 0.007 × 5 percent/Sv = 0.035 percent, not 3.5 percent. This demonstrates the programming defect; it does NOT validate that coefficient as lifetime cancer incidence or prescribe 0.035% as the patient's risk. The alternate low-value output also labels risk negligible without a demonstrated basis.

Input review additionally finds partial `parseFloat` parsing and an unknown-age fallback to adult factors. These require independently prescribed validation tests. Existing region/age conversion factors, reference DLP ranges, alert policy, and dose comparisons have not yet been fully traced to primary tables.

## Evidence reviewed before implementation

[ICRP Publication 147, 2021, DOI 10.1177/0146645320911864](https://journals.sagepub.com/doi/full/10.1177/0146645320911864), publisher full text, executive summary (b), (c), (f), (g), and Main Points: effective dose is a reference-person protection quantity; it can indicate approximate detriment and support procedure comparisons. Individual risk analysis requires organ/tissue doses and age-, sex-, and population-specific factors. Detriment-adjusted coefficients are not interchangeable with lifetime incidence. These passages support the interpretation boundary, not the current k-factor table. [Official ICRP publication summary](https://www.icrp.org/publication.asp?id=ICRP+Publication+147) is an accessible secondary route to the same publication's abstract and key points.
