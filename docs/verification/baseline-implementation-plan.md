current behavior, intended population and exclusions, every computation and
management claim, exact source/version/locator, independently derived expected
cases, and small allowed-file implementation tasks in the canonical record.

and validation research. Preserve real source conflicts; consequential choices
return to the clinician. Lawful source retrieval is bounded; comparator
agreement supports but does not establish correctness.

inputs, interacting rules, stale results, conditional fields, reset/recovery,
actual copied reports, keyboard and desktop/mobile behavior, rendered normal
and warning PDFs, synthetic privacy canaries and representative rule mutations.

unchanged evidence, not stale signatures. Changes in relevant source, code,
base, artifacts or clinical scope invalidate affected evidence.

changed-calculator live QA. Read back the authoritative receipt and relevant

events. Preserve paused jobs. Retire only proven-redundant clean worktrees with
